# 연구 질문 → 파라미터 결정표

수집 전에 이 표를 채우는 데 10분이 걸립니다. 안 채우면 나중에 반나절을 다시 씁니다.

| 결정 항목 | 우리 값 | 파라미터로 | 빠뜨리면 |
|---|---|---|---|
| 연구 질문 | 한국의 저출생은 다른 나라와 얼마나 다른가 | | |
| 필요 지표 | 합계출산율 | `indicator` / `itmId` | |
| 비교 대상 | OECD 주요 7개국 + 한국 | `country` | 나중에 국가 추가하며 재수집 |
| 분석 기간 | 2015~2025 | `date` / `startPrdDe`·`endPrdDe` | 추세 구간이 짧아 재수집 |
| 주기 | 연간 | `prdSe` | 분기 자료와 붙일 때 집계 기준 충돌 |
| 지역 단위 | 국가 (국내는 시도) | `country` / `objL1` | 국내외 결합 시 키가 안 맞음 |
| 단위 | 명 | | 환산 누락으로 값이 틀림 |
| 기준 | 확정치 우선, 없으면 잠정치 표시 | | 재현이 안 됨 |
