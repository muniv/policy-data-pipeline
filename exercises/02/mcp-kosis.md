# MCP로 KOSIS 표 찾기

2교시의 진짜 통증은 문서 읽기가 아니라 **KOSIS에서 tblId·itmId·objL1을 찾는 일**입니다. MCP 서버가 KOSIS API를 도구로 감싸면 에이전트가 표 검색과 메타데이터 조회를 직접 합니다.

## 준비 (수업 전)

1. KOSIS OpenAPI 인증키 발급: https://kosis.kr/openapi (회원가입 → Open API 사용 신청)
2. 환경변수 설정: `KOSIS_API_KEY=발급받은키` (셸 또는 `.env`)
3. 서버 설치: `pip install korean-stat-mcp`
4. 저장소 루트의 `.mcp.json`이 서버를 등록합니다. VS Code에서 저장소를 열고 `claude`를 실행하면 같이 잡힙니다.

`claude` 안에서 `/mcp`를 입력하면 연결된 서버가 보입니다. 안 보이면 `.mcp.json` 위치와 환경변수를 확인하세요.

이 서버는 공개 커뮤니티 프로젝트입니다(seolcoding/korean-stat-mcp, MIT). 기관 정책상 설치가 어려우면 건너뛰고 강사 화면으로 따라오세요.

## 실습

> 합계출산율 시도별 연간 통계표를 찾아서 요청에 필요한 파라미터를 알려줘. orgId, tblId, itmId, objL1, prdSe 를 표로.

에이전트가 도구를 두 번쯤 부릅니다. 통계표 검색, 그 다음 메타데이터 조회.

> 이 값으로 `references/api-registry.md`의 KOSIS 명세서를 채워.

**도구가 찾아준 값도 주장입니다.** 4단계 검증 호출은 그대로 갑니다.

## 여기서 선을 긋습니다

MCP 도구 결과는 모델 컨텍스트로 들어옵니다. 즉 "값을 읽히는 것"입니다.

| | 도구 (MCP) | 코드 (파이프라인) |
|---|---|---|
| 잘하는 일 | 표 찾기, 구조 확인, 빠른 조회, 인용 검증 | 대량 수집, 매달 재실행, 검증 후 산출물 |
| 규모 | 행 수십 | 행 수천 |
| 반복 | 한 번 | 매달 |
| 근거 | 대화 안 | raw/ 파일 |

표를 찾을 땐 도구, 파이프라인은 코드. 대화 안에서 2천 행을 읽히는 순간 재현성이 사라집니다.

## 다른 서버 (강사 시연, 3교시)

| 소스 | 서버 | 인증 |
|---|---|---|
| DART 공시 | korean-dart-mcp | OpenDART 키 |
| 법제처 법령·판례 | korean-law-mcp (`verify_citations`로 지어낸 조문 검출) | 법제처 OC |
| 공공데이터포털 | opendata-mcp | 포털 인증키 |

전부 커뮤니티 서버입니다. 설치 전 저장소 코드와 보안 스캔 결과를 확인하고, 키는 환경변수에만, 내부 자료는 도구에 넘기지 않습니다.
