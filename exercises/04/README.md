# 4교시 · 붙이고, 검증하고, 매번 다시 돌린다

15:00~17:00. 3교시에서 따로 가져온 세 갈래를 하나의 파이프라인으로.

**Claude Code가 없어도 이 교시를 전부 따라올 수 있습니다.** 각 프롬프트 아래 `관전 트랙` 상자에 터미널만으로 같은 것을 확인하는 방법과, claude.ai 무료 웹에서 해볼 수 있는 프롬프트가 함께 있습니다.

## 1. 규칙 파일 (15:00)

`CLAUDE.md`와 `SKILL.md`를 엽니다. 같은 요청을 규칙 파일 없이 / 있이 던져서 결과 차이를 봅니다.

> **관전 트랙** — 에이전트 없이 같은 것을 확인합니다.
>
> 두 파일을 열어 읽는 것만으로도 절반은 됩니다. **코드체계 · 출처 우선순위 · 금지사항 · 중단 조건** 네 가지가 어떻게 적혀 있는지 보세요. 여러분 기관에 옮길 때 가장 먼저 쓰는 파일입니다.
>
> **claude.ai 무료 웹** — `CLAUDE.md` 내용을 붙여넣고:
> *이 규칙 파일을 우리 기관용으로 바꾸려면 어느 항목을 고쳐야 할지 알려줘. 우리는 [기관명]이고 주로 [지표]를 다뤄.* 프롬프트를 다듬는 것보다 규칙 파일에 맥락(코드체계, 출처 우선순위, 금지사항, 중단 조건)을 넣는 쪽이 큰 지렛대입니다.

## 2. 세 갈래 붙이기 (15:15)

> 3교시에서 만든 API · 크롤링 · 내부자료 세 데이터를 하나의 패널로 합쳐. 지역 코드는 `references/region-codes.csv`로, 국가 코드는 ISO3로, 기간은 연 단위로, 단위는 명으로 맞춰. 사전에 없는 지역명이나 규칙으로 분류 안 되는 정책명은 판단하지 말고 코드북 4절에 미확인으로 남겨.

키 정합이 전부입니다. 행정구역코드와 법정동코드, ISO3, 연/분기, 명/천명.

하이브리드 정규화: 규칙(사전)으로 먼저 → 애매한 것만 판단 → 결과를 사전에 축적 → 다음 실행부터 규칙. `out/codebook.md` 4절에 "첫만남이용권 · 현금성 지원 · 미확인"이 찍히는 걸 확인합니다.

## 3. 검증 (15:45)

> `references/schema.md`의 중단 조건을 전부 검사하는 validate를 만들고, 통과하면 산출물을 만들어. 그 다음 데이터를 일부러 망가뜨려서 정말로 중단되는지 보여줘.

> **관전 트랙** — 에이전트 없이 같은 것을 확인합니다.
>
> ```bash
> python run.py --offline                  # 통과 8 / 확인 1 / 실패 0 · 292행
> python run.py --offline --break-check    # 실패 1 · 중단
> ```
>
> 두 번째 명령 뒤에 **`out/` 폴더가 갱신되지 않은 것**을 확인하세요. 검증에 걸리면 산출물이 아예 안 만들어집니다.
>
> `out/codebook.md` 를 열어 **4절 '판정이 필요했던 항목'** 도 보세요. 첫만남이용권과 산후조리 경비 지원이 **미확인**으로 남아 있습니다. 확정은 연구자가 합니다.

```bash
python run.py --offline --break-check
```

산출물이 만들어지지 않는 걸 봅니다. 중단 조건은 사람이 아니라 코드가 지킵니다.

## 4. 지표 추가 전체 사이클 (16:10)

이 강의에서 가장 보여드리고 싶은 장면입니다.

> KOSIS 출생아수 지표를 파이프라인에 추가해. `SKILL.md` 절차대로 진행해.

레지스트리 확인 → `config/sources.yml` 추가 → 변환 함수 → 허용 범위 등록 → `--offline` 실행 → 검증 → 코드북 · 대시보드 갱신. 4분 뒤 대시보드가 바뀝니다.

> **관전 트랙** — 에이전트 없이 같은 것을 확인합니다.
>
> 에이전트 없이 손으로 같은 일을 해볼 수 있습니다. `exercises/04/reference/README.md` 에 정답지가 있습니다.
>
> ```bash
> python exercises/04/reference/make_births_sample.py     # 스냅샷 198건 생성
> ```
>
> 그 다음 `exercises/04/reference/sources_births.yml` 의 두 조각을 `config/sources.yml` 에 옮겨 붙이고 `python run.py --offline` 을 돌리면 **292행 → 490행**이 됩니다. `out/dashboard.html` 을 새로고침해 보세요.
>
> 여기서 짚을 것 하나. **`normalize.py` 에 변환 함수를 새로 안 씁니다.** 소스 id 가 `kosis` 로 시작하면 같은 함수로 가게 되어 있어 **설정만 바꾸면 끝**입니다. 소스가 늘어도 스크립트는 그대로입니다.

6번 검증에서 멈추면 검사를 느슨하게 고쳐 통과시키지 않습니다.
