# 같은 지표, 세 가지 응답 형식

| 파일 | 형식 | 흉내낸 소스 | 결측 표기 |
|---|---|---|---|
| `response.json` | JSON | World Bank 식 (원소 2개 배열) | `"value": null` |
| `response.xml` | XML | 공공데이터포털 식 (`<items><item>`) | `<value></value>` 또는 `<value/>` 빈 태그 |
| `response.csv` | CSV | KOSIS 내려받기 식 | `-` 또는 공란 |

세 파일을 전부 표준 스키마로 옮겨 하나로 합칩니다. 결측은 형식마다 표기가 다르니 전부 사유 코드로 옮깁니다. **XML의 빈 태그에서 값이 조용히 사라지기 쉽습니다.** 국내 공공 API는 XML이 흔합니다.

CSV의 `-`와 공란은 다른 뜻일 수 있습니다(비공개 vs 미조사). 응답만으로는 모르니 사람이 정합니다.

수치는 구조 확인용 샘플입니다.
